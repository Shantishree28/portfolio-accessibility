# Accessible Portfolio Website

## Overview

This project is a multi-page personal portfolio website developed using Semantic HTML5 and modern web accessibility practices. The website follows WCAG accessibility guidelines and incorporates SEO-friendly metadata to ensure an inclusive and optimized user experience.

## Features

- Semantic HTML5 structure (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Accessible navigation with keyboard support
- ARIA labels for improved screen reader compatibility
- Skip-to-content link for accessibility
- SEO-optimized meta tags
- Responsive design for different screen sizes
- Accessible contact form with proper labels and fieldsets
- Clean and organized project structure

## Pages

- Home
- About
- Projects
- Contact

## Technologies Used

- HTML5
- CSS3

## Accessibility Considerations

The website has been designed following accessibility best practices:

- Semantic HTML landmarks
- Keyboard navigability
- Visible focus indicators
- Screen reader-friendly structure
- Proper form labeling
- Skip navigation link
