# Shanti Shree Portfolio Website

A modern, accessible, and fully responsive personal portfolio website developed as part of the RD Technology Internship program.

## Project Overview

This project demonstrates the implementation of:

- Semantic HTML5 structure
- WCAG accessibility best practices
- Responsive web design
- CSS Grid and Flexbox layouts
- Dark/Light mode theme
- SEO-friendly metadata
- Mobile-first development approach

## Features

### HTML5 & Accessibility
- Semantic HTML5 tags
- Skip Navigation Link
- Accessible Forms
- ARIA Labels
- Keyboard Navigation Support
- Lighthouse Accessibility Optimized

### Advanced CSS3
- CSS Grid Layout
- Flexbox Components
- Responsive Design
- CSS Variables
- Dark/Light Theme Toggle
- Modern Card-Based UI
- Mobile-First Architecture

### SEO Optimization
- Meta Description
- Keywords
- Open Graph Tags
- Responsive Viewport Configuration

## Pages

### Home
Introduction, skills, and featured projects.

### About
Educational background, strengths, and career goals.

### Projects
Portfolio projects displayed using responsive CSS Grid layouts.

### Contact
Accessible contact form with social and professional links.
